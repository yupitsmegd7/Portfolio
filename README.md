# Gourav Dutta · The Nocturne Portfolio

A Renaissance-at-night React portfolio combining machine learning, useful software, and writing.

## Experience
- Five sliding chapters: About me, Selected work, The craft, My journey, and Connect.
- A substantial opening biography and original candlelit atelier artwork.
- Nine curated projects with category filters, accessible detail dialogs, repository links, and known deployment links.
- Responsive layout, keyboard tabs, focus restoration, reduced-motion support, and locally bundled fonts.
- No contact form, tracking, database, API keys, or visitor data collection.

## Run
Use Node.js 22.13+ and pnpm. Install with `pnpm install`, develop with `pnpm dev`, check types with `pnpm exec tsc --noEmit`, and build with `pnpm build`.
